Any360 progress

How native each Xbox 360 title is on its way from a ReXGlue static recompilation (stage 0, the oracle) to a portable native codebase (stage 3): what the runtime still provides of what the title needs, what runs natively, and which components of the toolkit exist. Generated by tools/progress_page.py on 2026-10-30 from docs/coverage/; raw numbers in progress.json. Counts and public API names only: no game code or data.
