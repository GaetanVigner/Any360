Any360 progress

How native each Xbox 360 title is on its way from a ReXGlue static recompilation (stage 0, the oracle) to a portable native codebase (stage 3): the game's functions replaced by native C++, the system calls the runtime still provides, the render passes drawn natively, and the toolkit's components. Generated by tools/progress_page.py on 2026-10-30; raw numbers in progress.json, per-function inventories in data/. Counts, addresses and public API names only: no game code or data.

One square per function (left) and per system call (right), grouped by module and by library; hover a block for its numbers. Library ranges (XDK D3D runtime, CRT, import thunks) are replaced as a unit by Any360 rather than decompiled; the rest of the game's functions are the stage 2 work. Modules named code 82Xxxxxx are 1 MB areas not yet named by symbol recovery.
